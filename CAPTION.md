📊 Donezo — Modern Project Management OS • Ready-UIs Dashboard #01

Turning project management into high craft. ✨🚀

Here is Donezo, a modern full-page project & task management workspace engineered with pure HTML5, Tailwind CSS, and Vanilla JavaScript.

✨ What’s packed inside:
• Full-Page Edge-to-Edge Architecture with docked persistent sidebar & sticky command header (⌘F)
• 4 Bento KPI Metric Cards with monthly trend percentage indicators & clean SVG micro-badges
• Interactive Weekly Project Analytics pill-bar chart with dynamic floating tooltip & caret pointer
• Live Sprint Time Tracker engine (Interactive Play / Pause / Reset clock)
• Meeting Reminders widget with 1-click active Zoom call state & pulse beacon
• Team Collaboration roster with member avatars & status pills (Completed, In-Progress, Pending)
• Project Progress horseshoe radial arc gauge (41% ended) with dashed progress tracks
• Active Deliverables data table with interactive checkboxes, priority tags & member assignees
• Built-in Web Audio API sound synthesizer for tactile UI clicks on every interaction
• Daylight Clean ↔ Obsidian Dark Mode theme switch
• 100% Zero-build HTML + Tailwind CDN (Runs right in the browser with zero npm install)
• Fully responsive for desktop, tablet, and mobile with slide-in navigation sheet
